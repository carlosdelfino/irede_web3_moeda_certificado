O **iRede.c** é a moeda utilitária proposta para o ecossistema de certificados
iRede, com operação prevista na blockchain **Polygon**. Sua finalidade é
reconhecer a progressão do participante e conectar o aprendizado às
funcionalidades do programa.

## Como se ganha (proposta)

- **Conclusão de etapas** — a cada etapa concluída, o participante recebe
  iRede.c conforme as regras de distribuição vigentes.
- **Participação em desafios** — desafios específicos podem premiar iRede.c
  adicional.

## Como se usa (proposta)

- **Emissão de certificados** — emitir ou registrar certificados on-chain.
- **Desafios** — participar de desafios que exigem iRede.c como entrada ou
  stake.
- Outros usos utilitários definidos nos [requisitos]({{ 'requirements/' | relative_url }}).

## Características técnicas (previstas)

| Item | Direção |
| :--- | :--- |
| Padrão | ERC-20 (ou equivalente) na Polygon |
| Natureza | Token **utilitário** — não é produto de investimento |
| Emissão | Controlada por contrato, conforme regras do programa |
| Contratos | Repositório [smartcontracts](https://github.com/carlosdelfino/irede_web3_moeda_certificado_smartcontracts) |

> Os parâmetros de supply, distribuição e queima serão definidos nos
> requisitos e revistos antes de qualquer deploy.
