O projeto/Arquitetura
03 / Por dentro do ecossistema

Tecnologia que conecta a jornada.

Quatro módulos independentes, uma proposta integrada: conectar participação, certificados e moeda utilitária na Web 3.

Nesta página
Em construção

Proposta em fase de documentação e definição de requisitos.

O projeto é organizado como um repositório principal de documentação e orquestração com quatro submódulos Git independentes, um por módulo.

01 / EXPERIÊNCIA

Participante

O frontend apresenta a jornada, os certificados, os desafios e o saldo de iRede.c.

02 / ORQUESTRAÇÃO

API e serviços

O backend conecta as regras do programa à emissão e à integração com a blockchain.

03 / OPERAÇÃO

Administração

O dashboard reúne a gestão de participantes, etapas, emissões e parâmetros.

04 / REGISTRO

Smart contracts

Os contratos na Polygon deverão implementar o token iRede.c e o registro de certificados.

Esta é a arquitetura prevista. Os módulos estão em fase de documentação, e as integrações serão detalhadas nos requisitos antes da implementação.

Papel de cada módulo

Módulo Responsabilidade
backend API REST: emissão/validação de certificados, carteira de iRede.c, integração com a Polygon, autenticação.
frontend Interface do participante: jornada, certificados, saldo de iRede.c, desafios.
frontend_dashboard Interface administrativa: gestão de emissões, participantes, etapas e tokenomics.
smartcontracts Token iRede.c (ERC-20 ou equivalente) e contrato de registro de certificados na Polygon.

Fluxo de alto nível

  1. O participante conclui etapas — registradas pelo backend a partir das ações no frontend.
  2. A cada etapa, o backend credita iRede.c conforme as regras — refletidas on-chain pelos smartcontracts.
  3. O certificado é emitido; seu hash pode ser ancorado na Polygon.
  4. O dashboard administra participantes, etapas, desafios e parâmetros de emissão.
